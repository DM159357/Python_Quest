Python Quest + Web Dev Academy (Hindi UI update)

Preservation:
- Existing Python course files are retained from the supplied project ZIP.
- Web Dev Academy uses web-course-data.js and web-course.js.
- Learner-facing English Definition is not displayed; explanations use Hindi with necessary technical English terms.

Web Dev Academy features:
- HTML, CSS, and JavaScript courses.
- Course lessons grouped into three levels per course.
- Each lesson shows concept, coding example, expected result, wrong code, error explanation, and corrected code.
- Five practice panels per lesson, each with its own blank editor, Hint, and Solution controls.
- HTML and CSS preview; JavaScript console output runner (restricted browser APIs are blocked).
- Five-question lesson quiz with explanations.
- Lesson progress saved in this browser's localStorage.
- A level certificate becomes available when every lesson in that level is marked complete. Certificate can be printed or saved as PDF.

Important learner note:
- The five practice prompts include a core task, debugging, recreating the example, a variation, and an independent challenge. Some reference solutions are based on the lesson's existing example/fix and may need adapting for the learner's chosen variation. They are practice scaffolds, not a claim that every prompt has a fully unique authored answer key.
- The JavaScript runner is a learning sandbox, not a secure general-purpose runtime. Browser APIs and network access are intentionally restricted.
- Progress is stored locally in the browser. Clearing browser storage may clear progress.
- Certificates are local completion certificates, not externally accredited credentials.

To run: extract the ZIP, open Python_Quest_Combined5/index.html in a modern browser (or use VS Code Live Server).
